failure line) and green after; if a new test already passes, record that and why.

<files>`; packages are `cd packages/<name> && npx vitest run [--project <unit|pg>] [<files>]`. "The

`npx vitest run` in `packages/storage`, `packages/session-core`, `packages/catalog`,
`packages/log-import`, `packages/transcription` and `packages/ai-runtime`, and `npm run typecheck`.

group ends with the full suites green. Any change to an existing test's expected value outside design
D12's list is a stop: update the artifacts and ask the owner.

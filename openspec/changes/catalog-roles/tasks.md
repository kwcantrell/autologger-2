The first commit on `supabase-6b1-catalog-roles` holds only `openspec/changes/catalog-roles/`.
The PR targets `supabase-migration`, and the gates run with `GITHUB_BASE_REF=supabase-migration`.
One PR, no size budget (ADR 0024). Every `make stage-up` needs the owner's permission; the live dev
and stage checks are in proposal.md "After merge". Do not run `make dev-up` on this branch before
task 6.3: the migration file changes between its two steps (design D1).

Logs: keep every test and gate run under the session scratchpad as `6b1-<task>-<red|green>.log`,
and name the log in each `Evidence:` line. Each "test first" item is red before its change (record
the failure line) and green after; if a new test already passes, record that.

<files>`; packages are `cd packages/<name> && npx vitest run [--project <unit|pg>] <files>`. The
full-suite command used below is "the full suites": `cd server && npx vitest run --project unit
--project integration --project pg`, `cd packages/storage && npx vitest run`, `cd packages/catalog
&& npx vitest run`, and `npm run typecheck`.

and stage checks are in proposal.md "After merge".

the failure line) and green after; if a new test already passes, record that and why.

<files>`; packages are `cd packages/<name> && npx vitest run [<files>]`. "The full suites" means:
`cd server && npx vitest run --project unit --project integration --project pg`, `npx vitest run`

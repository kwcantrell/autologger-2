# event-generate-menu — design

## Approach

Extend the existing synchronous `POST …/events/generate` route with an optional
body. Keep Generate All / Custom on the append path; add a regenerate branch
that bulk-deletes auto rows after guards + slot acquire, then reuses the same
CLI turn. Web turns the toolbar button into a menu + Custom modal; filter rows
render checkmarks without `PopoverItem` selected tint.

## Decisions

### D1 — Server-side regenerate (locked)

Atomic delete+generate on the server after slot acquire. Avoids partial
client-side delete failures.

### D2 — Custom = selection only, never delete (locked)

`regenerate: true` + non-empty `selection` → `400`. Custom always appends for
the filtered instruction set.

### D3 — Menu trigger always “Auto Generate” (locked)

Only the first menu *item* flips Generate All ↔ Regenerate All based on any
loaded `auto_generated` event in the session.

### D4 — Selection entry model

`{ category_id, option_label?: string | null }`. Null/omit = button-level
`auto_instruction`. String = dropdown option with matching label and non-empty
option instruction. Filter snapshot categories so a category may appear with
only a subset of options and/or without the button-level instruction.

### D5 — Delete timing

After config/transcript/instructions/cap prechecks **and** successful
`tryAcquire`, before `driveAiTurn`. Failed guards never wipe. Hub helper
`deleteAutoGeneratedEvents()` in one transaction; broadcast via existing
`event.changed` path.

### D6 — Filter checkmarks scoped to EventLogSheet

Do not change global `PopoverItem` selected styling; EventLogSheet
`FilterDropdown` passes `selected={false}` and prefixes a checkmark when on.

### D7 — `has_auto` from loaded events

Detect Regenerate All from the events query already loaded in the sheet.
Accepted residual: autos only beyond the loaded page may delay the label flip.

## Risks

- Regenerate deletes all autos including categories later stripped of
  instructions — intended full wipe of auto attribution.
- Selection ignore-unknown can surprise if labels drift; empty-after-filter →
  400 mitigates silent no-ops.

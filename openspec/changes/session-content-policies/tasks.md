`packages/log-import`, `packages/transcription` and `packages/ai-runtime`, and `npm run typecheck`.

Order: every group ends with the full suites green and is committed separately, so each commit is
reviewable on its own (panel finding 2). Group 3 (commit 3a) changes the seam and the adapter with
no behaviour change: the hub passes one internal system caller, `session-hub`. Group 4 (commit 3b)
binds the callers. Inside groups 3 and 4 the tasks are test-first steps of one commit, because a
seam change does not compile halfway. Any change to an existing test's expected value outside
design D12's list is a stop: update the artifacts and ask the owner.

Keep each task's text, and later its `Evidence:`, in one block with no blank line: the evidence gate
reads only up to the first blank line.

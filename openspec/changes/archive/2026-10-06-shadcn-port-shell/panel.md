# Panel: shadcn-port-shell
Tier: 1 · Reviewers: assumption tester · Date: 2026-10-06

- [x] [critical] D3 had no guard against row navigation. Radix `DropdownMenuItem` is a `<div role="menuitem">`, so a menu-item click bubbles through the portal to the row's `onClick`, which only skips `button, a, input, select, textarea`. Choosing Rename, Archive, Delete or Close session would also select the row and navigate, and on mobile close the rail. Enter on the trigger or items also reaches the row's `onKeyDown`. No test checks `onSelectSession`. Evidence: scratch `at2/p.test.tsx` -> `item tag DIV`, `CLICK onRename 1 onSelect [["click"]]`, `ENTER item onSelect [...]`; baseline Popover -> `TODAY popover item click onSelect 0`. Resolved: D3 now stops propagation on `DropdownMenuContent` and widens the row's click and keydown guards to skip `[role="menu"], [role="menuitem"]` and any `button`. Task 3.3 adds failing-first tests that a click, Enter on an item, and Enter on the trigger never call `onSelectSession`.
- [x] [major] The Checkbox port breaks `TeamCard.test.tsx` L270–271 (`(morning as HTMLInputElement).checked`), which the plan didn't list: a Radix Checkbox is a `<button role="checkbox">` with no `.checked`. Evidence: scratch `at2/c.test.tsx` -> `CB tag BUTTON checked prop undefined aria-checked false`. Resolved: the proposal now lists four test updates, and D5 and task 4.2 move those assertions to `aria-checked`. The owner and admin rows have no checkboxes (`CB buttons in row 0`).
- [x] [major] D2's `RouteState` dropped the page frame (`ROUTE_STATE_PAGE`, `GATE_PAGE`) that `web-session-routing` "Deep-link resolution states" requires, and the `data-testid`/`data-variant` passthrough the tests query. No test pinned the frame. Evidence: `grep -rn "ROUTE_STATE_PAGE\|calc(100vh-2.2rem)" web/src` -> only `RouteLoadingState.tsx:21`, `SessionRoute.tsx:65`, `ChunkLoadBoundary.tsx:150`. Resolved: D2 adds a `frame: 'route' | 'gate'` prop that wraps the panel in the exported constant, plus a rest-props passthrough. Task 2.1 adds tests that each frame wraps in exactly its constant and that the test ids pass through.

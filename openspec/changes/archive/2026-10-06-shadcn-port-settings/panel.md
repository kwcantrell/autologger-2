# Panel: shadcn-port-settings
Tier: 1 · Reviewers: assumption tester · Date: 2026-10-06

- [x] [major] Ported buttons lose the mobile 44px touch-target floor: legacy `.btn` gets `min-height: 2.75rem` below 767px, but the shared Button default is `h-9` (36px) with no `max-md` floor (only the glass variants have one). Save, Close, Retry, Add show, the dialog actions and Copy/Add would shrink on phones, and the row drag/delete icons would drop to 24px. Evidence: `sed -n 1638,1650p web/src/shared/theme/tailwind.css` -> `/* Touch-target floor for the app-wide button … */ .btn { min-height: 2.75rem; }`; `grep -n "size: {" -A3 web/src/shared/components/ui/button.tsx` -> `default: 'h-9 px-[1.1rem] py-2 …'`. Resolved: design D2b adds an exported `TOUCH_TARGET = 'max-md:min-h-11'` applied to every button ported from `.btn` (row icons included, matching today's 44px on mobile); tasks 2.2/3.1/3.2 assert it, and the 4.1 QA eval measures ≥ 44px at 390.
- [x] [major] The disabled Save would lose its "No unsaved changes" tooltip: `Button`'s base sets `disabled:pointer-events-none`, so a `title` on the disabled button never shows on hover. Evidence: `grep -n "No unsaved" web/src/pages/index/components/HomeSettingsModal.tsx` -> `774: title={dirty ? undefined : 'No unsaved changes'}`; scratch test -> `Saved classes has pointer-events-none: true`. Resolved: design D2 moves the title onto a wrapping `<span className="inline-flex">` (the button keeps "no hover response when disabled"); task 2.2 asserts the wrapper's title.

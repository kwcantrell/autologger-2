# Panel: redesign-show-ignition
Tier: 1 · Reviewers: assumption tester · Date: 2026-10-07

- [x] [critical] The Settings view is a non-dialog overlay over a still-mounted workspace. Workspace hotkeys (1–9 log, Space, +/−, ?) yield only to `[role=dialog|alertdialog|menu]` and typing targets, so a digit pressed on a Settings tab or button would log into a live, possibly recording, session behind Settings. Evidence: `cat web/src/shared/ui/overlayOpen.ts` -> `OVERLAY_SELECTOR = '[role="dialog"],[role="alertdialog"],[role="menu"]'`; `grep -n "Dialog" HomeSettingsModal.tsx` -> `703: <Dialog`. Resolved: web-ui-system adds "The Settings view is modal to the console" (role=dialog, aria-modal); design D3 names `isOverlayOpen`; task 6.1 tests that 1 and Space do nothing over a rolling session.
- [x] [major] D8 and task 4.1 route `[` through "the existing global single-key shortcut layer", which does not exist. Listeners are per component, and the guarded ones live in the workspace, which is not mounted on `/` or `/teams`. Evidence: `grep -rn "addEventListener('keydown'" web/src` -> AppShell.tsx:116 (Escape only), SessionWorkspace.tsx:141, CategoryButtonStrip.tsx:304, AudioPlayer.tsx:374, useZoomRail.ts:802. Resolved: web-ui-system adds "Shell-level sidebar shortcut"; D8 specifies a new AppShell listener reusing `isTypingTarget`/`isOverlayOpen`; task 4.1 tests `[` on `/` with no session.
- [x] [major] web-session-routing "URL-addressed session state" still requires `/teams` to load as a lazy chunk with a teams-labelled loading frame and retry card, but D3 deletes that boundary and no delta modifies it. Evidence: `sed -n 46,52p openspec/specs/web-session-routing/spec.md` -> "`/teams` is now fetched as a lazy chunk … labelled for teams". Resolved: MODIFIED delta added. `/teams` renders home with Settings on Members and has no chunk of its own; both teams scenarios are rewritten for the overlay boundary.
- [x] [major] web-ui-system "Event-button rows defer their type control" becomes obsolete (type moves into the panel) but is neither modified nor removed.

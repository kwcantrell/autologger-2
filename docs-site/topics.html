Topics

The Topics tab breaks a session into topics: what was discussed, when, and for how long. Members generate topics from the transcript and edit them; they feed dashboards, search and the wiki.

How to generate topics

  1. Generate the session's transcript first (see Transcripts).
  2. Open the Topics tab.
  3. Click Auto generate.
  4. Rows appear with Session Time, Duration (s), Level and Summary.

Generating again replaces all topics, but only once the new run succeeds; if it fails, your current topics stay.

How to edit topics

  1. Click into a topic's Session Time, Duration (s), Level or Summary.
  2. Make the change and click or tab out to save it.
  3. To add a topic by hand, click Insert.
  4. Click a topic's jump button to listen from that point.

You can also ask the Assistant to create topics in conversation.

Requirements

Topic generation uses your own language model, added in Settings → Advanced (see AI and transcription accounts). Only one generation runs per session at a time.

Common problems

  • “No topics yet. Generate a transcript first”. Topics need a transcript.
  • “Add a language model in Settings → Advanced to generate topics.” Add your language model, or add topics by hand with Insert.
  • “Saving the topic failed.” Check the value (for example, a duration must be a number) and try again.

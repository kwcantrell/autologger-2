The session workspace

The session workspace is where a session is logged live and reviewed afterwards. This page explains its layout for every member; the pages linked below cover each part in detail.

What you see

  • The transport strip along the top: the timeline with its waveform and markers, the show and session name with the date, Status: (STOPPED, ROLLING, REC or PLAY), the running timecode, and the transport buttons.
  • Six tabs below it: Event Feed, Transcript, Topics, Assistant, Dashboards and Export.
  • Update wiki and Wiki page buttons beside the tabs, which connect the session to the show's wiki.

The top bar's status badge and colour follow the transport, so you can tell from anywhere in the app whether a session is rolling, recording or playing. Click it to return to the open session.

How to work through a session

  1. Open or create the session (Creating a session).
  2. Click Roll timecode and log events with the event buttons or the 1–9 keys (Live logging).
  3. Optionally click Record audio while rolling, or import audio (Recording audio, YouTube, Batch Import).
  4. Click Stop timecode when the session ends.
  5. Open Transcript and click Auto generate, then Topics and Auto generate.
  6. Review and correct the Event Feed, ask the Assistant, build a dashboard in Dashboards, and download files from Export.

How to switch tabs

Click a tab name. Switching tabs keeps your place: a running Assistant reply keeps streaming and unsaved row edits are kept. Each feed shows a count (for example “42 events”).

When features are not set up

Transcription and AI features run on your own provider accounts. When one is missing, the matching button stays visible but explains what to do, for example “Add a language model in Settings → Advanced to generate topics.” See AI and transcription accounts. Manual logging always works.

Importing logs from Google Sheets

If your team kept episode logs in Google Sheets (one tab per episode), Import Logs turns those rows into events on the matching sessions, lined up with each session's transcript. It is used by members bringing an existing archive into AutoLogger.

Prepare the workbook

  • Share the workbook so anyone with the link can view it.
  • Name each tab exactly like the session it belongs to (the session name in the show).
  • Log rows start at row 7. Column A is the timecode, column B the message, and column C an optional event type. Rows with an empty column A are ignored.
  • Column C should match one of the show's event buttons or dropdown options. A blank or unknown type is logged under the button named OTHER (an unknown type is added to the end of the message), so give the show an OTHER button.

How to import logs

  1. Click Import in the sidebar to open Batch Import.
  2. Choose the Show.
  3. Click Import Logs, paste the Public Google Sheets URL and click Use URL.
  4. Click Start Import. The progress list shows “Importing logs…” and then a line per tab: imported, skipped (no session with that name) or failed.

Each session's events are placed by matching the log messages against its transcript, so the times line up with the audio even if the sheet's timecodes were offset. Rows already in the session (same message at the same time) are skipped, so running the import twice does not duplicate events.

Requirements

  • Each session needs a transcript. If it has none, AutoLogger tries to generate one using your own speech-to-text key; add it in Settings → Advanced first.
  • Log import must be enabled on the server; if it is not, ask your administrator.
  • You need access to the show. If your access is removed during an import, it stops; sheets already imported stay.

Common problems

  • A tab is skipped. No session in the show has exactly that name. Rename the tab or the session and import again.
  • A session fails to sync. Too few log messages matched words in the transcript to line them up safely. Check that the right workbook tab and session are paired and that the transcript is complete.
  • “Skipped transcript generation…”. Add a speech-to-text key, or generate the transcript in the session first.

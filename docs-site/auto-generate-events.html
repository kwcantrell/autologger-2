Auto-generating events

Auto generate reads a session's transcript and logs events for you, following instructions you attach to each event button (for example “Log when the host introduces a new segment”). It is used by members who want a first-pass log of a recorded session.

Before you start

  • The session needs a transcript (see Transcripts).
  • At least one event button of the show needs an auto-generate instruction (set by an owner or admin in Event buttons).
  • You need your own language model in Settings → Advanced (see AI and transcription accounts).

How to generate events from all instructions

  1. Open the Event Feed tab.
  2. Click Auto generate.
  3. Choose Generate All. The button shows Generating… while it works.
  4. When it finishes, the toolbar says how many events were created, for example “Created 12 events.” New events are marked as auto-generated and placed at the matching point of the transcript.

How to generate from selected instructions

  1. Click Auto generate and choose Custom.
  2. In Custom event generation, tick the button and option instructions to use. Each button's own instruction is listed as Button instruction; dropdown options are listed by name.
  3. Click Generate.

How to regenerate

  1. Once a session has auto-generated events, the menu offers Regenerate All instead of Generate All.
  2. Choose it and confirm Delete and regenerate.
  3. The earlier auto-generated events are replaced only if the new run succeeds. A failed run, or one that finds nothing to log, leaves them in place. Events you logged by hand are never touched.

Permissions

Anyone who can open the show can run Auto generate, using their own language model account. Only owners and admins can write the instructions.

Common problems

  • “No event buttons carry auto-generate instructions yet.” Ask an owner or admin to add instructions in Settings › Event buttons.
  • “Add a language model in Settings → Advanced to generate events.” Add your language model; manual logging still works meanwhile.
  • “… per-run cap reached”. One run creates a limited number of events. Review them, then run again or use Custom for the rest.
  • On / Off buttons cannot auto-generate events.

Creating a session

A session is one recording or live event: one timeline with its events, audio, transcript, topics and dashboard. Members create a session in a show before logging or importing audio.

How to create a session

  1. Click New session at the top of the sidebar (or New session / Start a session on the home screen).
  2. In the New Session dialog, choose the Show. Only shows you can open are listed, shown as Name (CODE).
  3. If the show names sessions by episode number, type the Episode.
  4. Optionally type Notes (optional).
  5. Optionally open Import audio from YouTube to attach a video's audio (see Importing audio from YouTube).
  6. Optionally open Timecode settings to change the Frame rate or Start offset (frames). Choose Other… to type a Custom fps between 1 and 120. The defaults come from your team's Default frame rate.
  7. Click Create & open. The new session opens in the workspace.

How sessions are named

Each show has a Code and a Suffix (set in Shows). A new session's name starts with the show code and ends with either the date or the episode number you typed, depending on the suffix. You can rename a session at any time (see Managing sessions).

Permissions

Anyone who can open a show can create sessions in it. Owners and admins can open every show of their team; members only the shows they have been given access to.

Common problems

  • No New session button. The current team has no show you can open. Switch show or team in the top bar, or ask an owner or admin for access.
  • “No shows linked to this team”. The team has no shows yet. An owner or admin can add one in Shows.
  • “Enter an episode.” The show uses episode numbers; fill in Episode.

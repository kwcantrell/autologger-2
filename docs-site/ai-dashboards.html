AI dashboards

The Dashboards tab turns a session's transcript, topics and events into a visual summary: talk time by speaker, a topic timeline, events by category and more. An AI agent can propose a starting dashboard, which you then edit directly. Used by members and producers reviewing a session.

How to design a dashboard with AI

  1. Open the session and click the Dashboards tab. With no dashboard yet you see “No dashboard for this session yet”.
  2. Click Design with AI, or type a request in the conversation on the right (“Ask for a starting dashboard…”) and click Send.
  3. If the agent asks a question, click one of its options, or type an answer under Or describe it: and press Enter.
  4. The proposal appears as a draft: “Draft — the agent proposed this dashboard.” Click Keep to save it, or Discard.
  5. Ask for changes in the conversation, for example “add a question-density widget”.

How to build or edit a dashboard yourself

  1. Click Start blank for an empty grid, or Edit on an existing Session overview.
  2. Click Add widget and choose from Add a widget: Session duration, Talk time by speaker, Utterance counts, Questions asked, Filler words, Topic timeline, Events by category, Event density or Transcript excerpt. Widgets that cannot show data for this session are marked Unavailable with the reason.
  3. Drag a widget to move it and drag its corner to resize it. With the keyboard: arrow keys move, Shift+arrow keys resize, Enter renames, Delete removes.
  4. Click Remove widget to delete one.
  5. Click Done. Changes are saved as you make them.

Things to know

  • Widgets always show the session's own data. When data is missing (for example no transcript) a widget says Data unavailable and why, rather than showing zero.
  • Each session has its own dashboard.

Requirements

You can always build a dashboard by hand. Designing with AI must be enabled on the server; if it is not, the conversation says the dashboard designer isn't configured; ask your administrator to enable it.

Common problems

  • “Failed to save the dashboard.” Check your connection; the change is retried the next time you edit.
  • The dashboard area stays empty during a design. It fills in once the agent's turn finishes.

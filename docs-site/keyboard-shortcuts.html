Keyboard shortcuts

AutoLogger is built to be driven from the keyboard during a live session. This page lists every shortcut for members logging live and anyone reviewing a session. Shortcuts never fire while you are typing in a field or while a dialog is open.

How to see the shortcut list in the app

  1. Open a session.
  2. Press ?, or click the keyboard button (Keyboard shortcuts) next to the transport controls.
  3. The Keyboard shortcuts dialog opens. Press Esc to close it.

In a session

KeysWhat they do
1–9Log the 1st to 9th event button (while timecode is rolling and the buttons are shown). Holding a key down logs only once.
SpacePlay or pause recorded audio.
← →Move the timeline 1 second when the playhead is focused; hold Shift to move 10 seconds.
+ −Zoom the timeline in or out.
EscClose dialogs, cancel batch edit, close the drawer.
?Open the shortcut reference.

Anywhere in the app

KeysWhat they do
Ctrl+K (⌘+K on a Mac)Open Search.
[ or Ctrl+B (⌘+B) Show or hide the sidebar.

In the dashboard editor

With a widget focused while editing a dashboard: arrow keys move it, Shift with an arrow key resizes it, Enter renames it, and Delete or Backspace removes it. See AI dashboards.

Common problems

  • The number keys do nothing. Event buttons only log while timecode is rolling. Click Roll timecode first, and click somewhere outside any text field.
  • Some keyboard layouts need Shift for digits. That is fine; Shift is allowed with the number keys.

Live logging with timecode

Live logging is the core of AutoLogger: while a session's timecode rolls, members press event buttons (or number keys) to stamp events at the current timecode. This page is for the operator running the session.

The transport buttons

ButtonWhat it doesWhen it works
Play or pause audioPlays recorded audio from the playhead.While stopped and the session has audio.
Roll timecodeStarts the session clock. Status changes to ROLLING.While stopped.
Record audioRecords from your microphone. Status changes to REC.Only while timecode is rolling.
Stop timecodeStops the clock (and any recording).While rolling or recording.

Hover over a button to see its name. Next to them are Previous marker, Next marker and the Keyboard shortcuts button.

How to log a live session

  1. Open the session.
  2. Click Roll timecode. The status shows ROLLING, the timecode starts counting, and the show's event buttons appear in the timeline strip.
  3. When something happens, click its event button or press its number key (1 for the first button through 9 for the ninth). A “Logged.” message confirms it, and the event appears in the Event Feed and as a marker on the timeline.
  4. When the session ends, click Stop timecode.

How each kind of event button behaves

  • Button: logs one event named after the button.
  • On / Off: each press logs the next state (its On label, then its Off label), so you can mark when something starts and stops.
  • Dropdown: opens Choose option. Click an option to log it. If the option needs context, AutoLogger asks you to Add context: type it and press Enter or click Log (Back returns to the options).
  • Text: opens Log note. Type the Note and press Enter or click Log.

Dropdown and text events are stamped at the moment you pressed the button, not when you finish typing.

Several people at once

Everyone with the session open sees the same timecode and events live. Any member can roll or stop the timecode, and a Stream Deck running the Companion module can drive the same session. Only one browser can record audio at a time.

Permissions and set-up

Anyone who can open the show can log. The event buttons, their order and their number keys are set per show by owners and admins in Event buttons. Only the first nine buttons have a number key.

Common problems

  • No event buttons. Buttons appear only while timecode is rolling. If they still do not appear, the show has no buttons yet; ask an owner or admin.
  • “Unresolved recording” dialog. The log shows a recording that started but never stopped (for example after a crash). If someone else may still be recording, click Cancel. Only click Add synthetic stop if that recording really ended.
  • Leaving the session while rolling. If you started the timecode in this browser, leaving the session stops it.

AI and transcription accounts

Transcripts, topics, the Assistant, auto-generated events and wiki suggestions run on your own provider accounts, so each person's usage is billed to them. Every member who uses these features sets them up once in Settings → Advanced.

How to add a language model

  1. Open Settings and choose Advanced under You.
  2. On the Language model tab, choose the Provider: OpenAI-compatible, Anthropic, OpenAI or Google.
  3. For OpenAI-compatible, fill in the Base URL of the service.
  4. Type the Model name your provider gives you.
  5. Paste your API key.
  6. Click Save. The card shows Connected.
  7. Click Test connection to check the saved key and model.

The language model powers the Assistant, topic generation, event generation and wiki updates.

How to add speech to text

  1. In Advanced, open the Speech to text tab.
  2. Choose DeepGram as the Provider.
  3. Optionally set the Model (nova-3 supports speaker labels).
  4. Paste your DeepGram API key and click Save.
  5. Click Test connection. It checks the key with a quarter second of silence.

How to replace or remove a key

  • To replace it, click Replace, paste the new key and click Save.
  • To remove it, click Remove and confirm. Features that use it stop working until you add one again.

Things to know

  • Keys are stored encrypted, used only for your own requests and jobs, and never shown again after you save them. The card only shows the last four characters.
  • Session content (audio for transcription; transcript and topics for AI) is sent to the provider you choose, and that account pays for it.
  • Some servers also offer Claude CLI (operator), available only to operator accounts.
  • “Transcription and AI features are limited to approved users on this server.” If you see this, ask your administrator to approve your account.

Common problems

  • The test fails. Check the key, model name and (for OpenAI-compatible) base URL. Save your changes first: the test checks the saved choice.

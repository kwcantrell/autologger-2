The AI Assistant

The Assistant tab is a chat about the session you have open. Members and producers ask it questions about the transcript, or ask it to create topics, instead of re-listening to the recording.

How to ask the Assistant

  1. Open the session and click the Assistant tab.
  2. Type in Message the AI assistant…, for example “What did the guest say about the budget?”
  3. Press Enter or click Send. Use Shift+Enter for a new line.
  4. The reply appears as it is written, marked AI:. While it looks things up you may see “Using tool: …”.
  5. To stop a reply early, click Stop.
  6. Ask follow-up questions; the Assistant remembers the conversation.

Things to know

  • The Assistant only reads the session you have open.
  • The conversation is not saved. It survives switching tabs, but reloading the page or opening another session starts a new one.
  • It runs on your own language model account, which pays for it. Session transcript and topics are sent to that provider.

Common problems

  • “Add a language model in Settings → Advanced to use the assistant.” Add your language model (see AI and transcription accounts). The message clears once you save one.
  • “Connection to AI chat was lost before the turn finished.” Send the message again.
  • Answers are vague. Generate the transcript and topics first; the Assistant works from them.

Event buttons

Event buttons are the logging strip operators press during a live session. Each show has its own set, its own colour palette, and optional instructions that let AutoLogger log events automatically from a transcript. Owners and admins set them up; everyone uses them.

How to add an event button

  1. Choose the show in the top bar, then open Settings → Event buttons.
  2. Click Add button.
  3. Type the Name (shown on the button and as the event's category).
  4. Choose the Type:
    • Button: logs one event with the button's name.
    • Dropdown: you pick an option when logging; the option becomes the event message.
    • Text: you type a short message when logging.
    • On / Off: toggles between two states and logs each change.
  5. Pick a Colour from the show's palette. The Preview shows the button.
  6. For a Dropdown, fill in each option under Options and use Add option for more. Tick Needs context on an option to ask for a note after it is chosen.
  7. For On / Off, fill in the On label and Off label.
  8. Click Add button.

How to order buttons and their number keys

  1. Click Edit on a button.
  2. Under Position, click Move up or Move down.
  3. Click Save. The first nine buttons get the keys 1 to 9; the list shows each button's key.

How to write auto-generate instructions

  1. Edit a button and find Auto-generate.
  2. In Instruction, describe when the event should be logged, for example “Log when the host introduces a new segment.”
  3. For a Dropdown, you can also fill in Instruction for this option to say when each option should be picked.
  4. Click Save. Buttons with instructions are listed as “Auto-generates”.

On / Off buttons cannot auto-generate events. See Auto-generating events for running it.

How to change the colours

  1. Under Palette, choose a preset: Default, Neon, Desert or Aqua.
  2. Or change one of the Colours; the palette becomes Custom.

How to copy buttons from another show

  1. Under Copy from another show, choose the show in Copy buttons from.
  2. Click Copy and confirm Replace buttons. This show's buttons and colours are replaced with a copy of the other show's.

How to delete a button

  1. Click Edit on the button.
  2. Under Delete, click Delete, then Click again to delete.

Events already logged with it stay in their sessions.

Permissions

Only owners and admins can change event buttons. Members see them read-only.

Common problems

  • Sheets log import puts everything under OTHER. Add a button named OTHER and make sure button and option names match the sheet's type column; see Importing logs from Google Sheets.
  • A button has no number key. Only the first nine have one; move it up.

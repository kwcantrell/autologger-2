AutoLogger Help

AutoLogger is a session-logging workspace. You log events against running timecode during a live session, record or import its audio, generate a transcript and topics, and then analyse the session afterwards — so anyone on your team can find any event, word or theme without re-listening to the recording.

New here? Start with Signing in, then Getting around AutoLogger. Each page below explains one feature step by step, using the names you see on screen.

How to use this help

  1. Find your task in the groups below.
  2. Follow the numbered steps; words in bold are the labels on screen and keys look like Esc.
  3. Check the Permissions and Common problems notes at the end of each page.

Exporting a session

The Export tab downloads a session's data as files you can open in a spreadsheet or another tool. Any member who can open the session can export it.

How to download a session's data

  1. Open the session and click the Export tab.
  2. Click the file you want:
    • Event feed CSV: every logged event, one per row.
    • Transcript CSV: the transcript, with the word count shown on the button.
    • Topics CSV: the topics, with the topic count shown on the button.
    • Event feed JSONL: the events in a line-per-event format for other software.
  3. Your browser saves the file to your downloads folder.

Common problems

  • Transcript CSV or Topics CSV is greyed out. The session has no transcript or topics yet. Generate them first.
  • Edits are missing from the file. Finish editing (click out of the row, or Save changes in batch edit) before exporting.

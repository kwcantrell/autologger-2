Batch Import: folders and playlists

Batch Import brings in many recordings at once: a folder of audio files from your computer, a YouTube playlist, or both. It creates one session per recording in the chosen show, without you opening each one. It is used by members preparing an archive or a season.

How to import a folder of audio files

  1. Click Import in the sidebar (under New session). The Batch Import dialog opens.
  2. Choose the Show.
  3. Click Import Audio and pick a folder. Its name appears under the button.
  4. Click Start Import.
  5. Watch the progress list: each recording shows as completed, skipped, uploading or failed. The list stays until you close the dialog.

How files become sessions

  • Supported files: MP3, WAV, AIFF, M4A, MP4, OGG, WEBM and FLAC.
  • Each file becomes a session named after the file (without its extension).
  • Files in the same folder named with -1, -2, -3… endings (for example Episode 12-1 and Episode 12-2) are joined in order into one session called Episode 12. The numbers must start at 1 with no gaps; otherwise each file is imported on its own. Joined parts may be at most 150 MB together.
  • If the show already has a session with that name, the recording is skipped as “already in the system”.

How to import a YouTube playlist

  1. In Batch Import, choose the Show.
  2. Click Import YouTube Playlist, paste the playlist link (public or unlisted) and click Load playlist.
  3. The playlist's videos appear, all importable ones ticked. Use Select all, Select none, or type From and To positions and click Apply range. Greyed videos cannot be imported and say why (unavailable, live now, upcoming, or over 4 hours).
  4. Leave Use publish date ticked to date each session by its video.
  5. Optionally tick Autogenerate after import and choose steps (see below).
  6. Click Start Import. Videos are imported one at a time, each into a new session named after the video's title. Videos already in the show are skipped.

How to fill in transcripts and more after a playlist import

  1. Tick Autogenerate after import.
  2. Choose the Steps: Transcripts, Log events, Topics and Wiki, and how wiki output is handled.
  3. Click Start Import and confirm Import and autogenerate. When the import ends, a batch autogenerate job starts for the videos this import brought in.

Importing logs at the same time

Import Logs in the same dialog adds events from a Google Sheets workbook; see Importing logs from Google Sheets. When you run several parts together, AutoLogger imports the folder first, then the playlist, then the logs, so logs can match sessions the audio import just created.

Permissions and requirements

  • Import appears only if the current team has a show you can open.
  • Playlist import needs YouTube import enabled on the server; if not, the playlist will not load and you see why. Ask your administrator to enable it.
  • Autogenerate after import appears only for owners and admins, needs your own transcription and language-model accounts, and covers at most 1000 videos.

Common problems

  • Start Import is greyed out. Choose a show and at least one of: a folder, a ticked playlist video, or a logs link. With autogenerate ticked, the reason is shown under it (for example “Pick at least one step.”).
  • Closing the dialog stops the run. Sessions already imported are kept. Clicking outside the dialog or pressing Esc does not close it while it runs.
  • “Still importing … on the server”. Run the import again later; the unfinished session is picked up rather than duplicated.

Reviewing and editing the Event Feed

The Event Feed tab lists every event logged in a session, with its timecode, wall-clock time, event button and message. Members use it to correct the log during and after a session.

What you see

Each row shows a jump button, the time, the Event (the event button that logged it) and the Message. Events created by Auto generate carry a small sparkle mark (“auto-generated”). Click a column heading to sort by it.

How to choose the time display

  1. Click Time display in the feed toolbar.
  2. Choose Session Time (the session timecode) or World Clock (the real time of day the event was logged).

How to filter the feed

  1. Click Filter.
  2. Tick or untick event buttons to show or hide their events. The menu stays open so you can change several at once.
  3. Tick Internal to also show automatic entries such as “Recording 1 Started”.

How to fix an event while the session is live

  1. While timecode is rolling (or audio is recording), click into a row's time, event or message field.
  2. Make the change. Choose a different event button from the Category list if needed.
  3. Click or tab out of the row. The change is saved and an “Updated.” message confirms it.

Your unsaved text is kept even if new events push the row off screen.

How to edit many rows after the session (batch edit)

  1. Stop the timecode and any recording.
  2. Click Edit in the feed toolbar.
  3. Change times, event buttons and messages in as many rows as you like. To remove a row, click Delete row; click Restore row (UNDELETE) to change your mind.
  4. Click Save changes to apply everything, or Cancel (or press Esc) to discard. Discarding asks Discard changes; choose Keep editing to go back.

How to delete a single row

  1. Hover over the row and click Delete row.
  2. Confirm Delete log row. This cannot be undone.

When someone else changed the same row

If another person saved a change to a row after you started editing it, a Row changed dialog shows their version next to yours. Choose Overwrite to save yours, or Keep theirs to drop your edit. For a delete, choose Delete anyway or Keep theirs. Closing the dialog saves nothing and keeps your draft.

Permissions

Anyone who can open the show can edit its events. Auto-generated events cannot be edited or deleted one by one; to replace them, regenerate (see Auto-generating events).

Common problems

  • Edit is greyed out. Batch edit is “Available when timecode is stopped and audio is not recording.”
  • “Save stopped. The remaining changes are still pending.” Some rows could not be saved. Fix the reported problem and click Save changes again.
  • “No events logged.” Nothing has been logged yet; roll timecode and use the event buttons.

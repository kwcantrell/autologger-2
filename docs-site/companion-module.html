Stream Deck and the Companion module

The AutoLogger module for Bitfocus Companion lets an operator drive a live session from a Stream Deck: roll and stop timecode, record, play and log events, with the timecode and session name shown on the keys. It is set up by the operator who runs the hardware.

How to create a device token

  1. In AutoLogger, open Settings → Companion devices (under You).
  2. Type a Device name, for example Booth A, so you can tell it apart later.
  3. Click Add device.
  4. The Device token dialog shows the token. Click Copy. Copy it now: it won't be shown again.
  5. Click Done.

The Stream Deck acts as you: it can only reach the sessions you can open.

How to connect Companion

  1. In Companion, add a connection using the AutoLogger module.
  2. Fill in AutoLogger server URL with the address of your AutoLogger server.
  3. Paste the token into Device token (required).
  4. Leave Poll interval (ms) at 1000 unless told otherwise.
  5. Save. The connection turns OK once it reaches the server.

How to set up the keys

  1. In Companion's presets, open the AutoLogger category.
  2. Drag the presets you want onto your Stream Deck:
    • Roll / Stop: rolls or stops timecode; shows the session name and timecode and lights while rolling.
    • Record: starts or stops audio recording; lights while recording.
    • Play: plays or pauses recorded audio.
    • Log event: logs an event; edit the key to choose the Category (an event button of the active show) and an optional Message.
  3. You can also build your own keys with the actions Log event, Transport (roll/stop) (Toggle, Roll or Stop), Record (Toggle, Start or Stop) and Play (toggle), the feedbacks Take is rolling, Recording, Playing and No active session (warn), and variables such as session timecode, deck title, show name and logged event count.

How to run a session from the Stream Deck

  1. Open the session in AutoLogger in a browser and keep that browser open. The module acts on the session that browser has open.
  2. Check the session name shown on the keys before pressing; with several tabs open the active session can change.
  3. Press Roll / Stop to roll, then Log event keys as things happen.
  4. Record and Play commands are passed to the browser, which shows a short “Companion: …” message. If delivery fails, the module's last-command-error variable says why.

How to revoke a device

  1. In Settings → Companion devices, find the device (it shows when it was created and last used).
  2. Click Revoke and confirm. Its token stops working at once.

Common problems

  • “Device token invalid or revoked”. The token was revoked, mistyped, or unused for 90 days (it shows Expired in Settings). Create a new device and paste its token.
  • “Cannot reach AutoLogger server”. Check the server URL and the network.
  • Record does nothing. Timecode must be rolling, and only one client can record at a time; “Another client holds the recording lease.” means someone else is recording.
  • Playing state lags. The playing light is reported by the browser on a best-effort basis; the rolling and recording lights are exact.

Importing audio from YouTube

Instead of recording live, a member can attach the audio of a YouTube video to a session, for example a published episode. The audio is placed on the session's timeline like a recording, ready for a transcript.

How to import a video when creating a session

  1. Click New session and choose the Show.
  2. Click Import audio from YouTube to open that section.
  3. Paste the link into YouTube video link.
  4. Leave Use the video's publish date as the session date ticked if you want the session dated by the video; untick it to keep today's date.
  5. Click Create & open. The session opens and its status shows Importing YouTube Audio. Transport controls are locked until the import finishes.

If the import fails

A YouTube import failed dialog asks what to do:

  1. To try another video, paste a new link and click Import (or Try a different link).
  2. To keep the session and log without audio, click Continue without audio.
  3. To remove the session that was just created, click Don't create session.

Importing a whole playlist

To create one session per video of a playlist, use Import YouTube Playlist in Batch Import.

Requirements

  • YouTube import must be enabled on the server. If it is not, the import fails with a message saying it is unavailable; ask your administrator to enable YouTube import.
  • An import cannot start while the session is recording audio.
  • Only one import runs per session at a time.
